# 文件查看、下载与可选的工作区外访问

适用：Herdr Pocket **0.2.17 / versionCode 20**，电脑 Relay **0.23.5+codexfix.11**。Gateway codexfix.6 不需要更新；使用原有配对与端到端加密，不添加 HTTP 下载地址或公网端口。

## 使用

- 点对话中的本地文件链接、文件卡片，或文件列表中的文件，进入查看页。支持 Markdown 链接、Codex 文件引用、明确的内联/绝对路径；路径带空格时优先使用 Markdown 链接。
- 支持的图片/PDF（最多 12 MiB）、文本（最多 1 MiB）可以预览。超限、格式不支持或预览失败时显示文件信息，仍可下载或分享原文件。图片解码还有像素/尺寸限制。
- 下载分片写入手机私有缓存，显示已传输/总大小，允许取消。完成后“下载”打开 Android 保存位置选择器，“分享”打开 Android 分享面板。
- 下载没有沿用 12 MiB 预览上限；每片最多 512 KiB，不将整份原文件累积在内存。需要足够缓存空间，另存还需要目标位置的空间。单次下载最多一小时，网络/文件变更失败后重试从头开始，**暂不支持断点续传**。
- 取消/失败删除本次临时文件；成功分享的缓存保留供目标 App 读取，App 启动时清理超过一天的共享缓存。不撤回已经导出的文件或其他 App 收到的副本。

## 可选：访问工作区以外

在 **我的设备 → 对应电脑 → 工作区外文件访问** 中开启。默认关闭。只有已配对的控制者设备可更改自己的设置，开启前提示私密文件风险。

授权按 **当前手机凭据 × 当前电脑 Relay** 持久化在 Relay 的设备数据库中，不影响其他手机；新配对默认关闭。App 缓存只影响展示，服务端权限才是最终依据。

开启后仍从 Agent 工作目录开始浏览，但可返回 **`/` 根目录**、输入绝对目录、打开工作区外的文件引用。相对对话引用仍以 Agent 的实际 cwd 为基准，Markdown 内链接以当前文档目录为基准。关闭后恢复工作区范围；未完成的读取/下载停止，后续分片被拒绝。

**风险与边界：**

- 可以读到 Relay 运行用户有权限读取的普通文件，可能包括密钥、配置和其他私密资料。不是系统权限提升；不能读取操作系统本身拒绝访问的文件。
- 仅扩展浏览/预览/加载/下载；不允许越界修改、删除、上传覆盖或对系统目录执行 Git 操作。
- 文件读取仍绑定确切 Agent/terminal/session/generation，并在读取前后校验授权；切换 Agent、工作目录变化或撤销凭据不会把旧请求转投其他会话。
- 仍使用 descriptor-rooted 路径解析、普通文件检查，拒绝无效路径、最终符号链接文件、设备/管道等特殊类型。目录分页原有数量/时间限制保留。
- 外部 HTTPS 链接经确认交给浏览器，不携带 Relay 凭据；不会把远程 URL 当作电脑文件下载。

## 协议

- `workspace_file_download_v1`：`workspace_file_download` 为只读操作，`metadata_only:true` 仅返回信息、`preview_available`/原因、只读 `download_revision`；实际数据请求必须带匹配的 `expected_revision`，游标是规范化字节偏移。
- 响应分片含 `chunk_sha256`，手机验证路径、总大小、revision、偏移、每片散列、游标连续性和最终长度。revision 绑定文件大小、mtime 和可用的 inode/ctime；传输中更换/修改文件必须重新开始。它**不是写入令牌，也不是整文件 SHA-256**。
- `filesystem_read_opt_in_v1`：`file_access_get` 读取自己的设置；`file_access_set`（协议 v3、控制者、有审计）要求显式布尔 `filesystem_read`，不能指定其他设备受益。
- 文件类请求默认 `file_scope:workspace`。仅设备已获授权时接受 `file_scope:filesystem`，路径相对于 `/`；没有授权不能通过伪造 App 状态或请求字段扩大范围。
- 生效操作：`workspace_list`、`workspace_file`、`workspace_file_read`、`workspace_file_download`。下载/预览共用并发槽与逐次授权复查，不调整 Gateway 限制。
- 旧 Relay 不显示扩展权限设置，新能力需要升级电脑 Relay；旧配对不必重建。
