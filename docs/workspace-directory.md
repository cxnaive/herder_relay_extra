# 原生工作区：逐层目录分页

Android 0.2.15 与 Relay `0.23.5+codexfix.9` 修复大项目的目录显示。旧 `workspace_tree` 递归扫描整个项目，最多 4,000 项；一个靠前的大目录可能耗尽预算，令根目录后面的兄弟文件夹都缺失。它不是工作目录真正发生了切换。

## 使用方式

- 从具体 Agent 打开工作区；标题使用 Herdr Tab 名称，路径显示 Relay 确认的规范化工作目录和当前子目录。
- 只读取当前层，进入文件夹或返回上级都请求那一层。普通目录、隐藏目录和生成目录均可列出，不会因为递归扫描额度被其他层吞掉。App 默认隐藏点号开头的条目，可通过“显示隐藏文件/目录”开关查看，选择会保存在本机。
- 大目录点击“加载更多目录项”，界面显示当前目录的已加载数量；筛选只覆盖已加载的条目，不宣称已经搜索整个项目。
- 符号链接和特殊文件不会被跟随。读取失败、分页过期和旧树截断与“真正为空”分开提示；目录变化后可刷新当前层。
- 仍是只读浏览。`workspace_file_read_v1` 可提供 PDF/Markdown/图片查看和下载，不代表允许保存修改。

## 接口与边界

- 能力：`workspace_directory_v1`；只读操作：`workspace_list`。
- 请求带协议 v3、已鉴权设备和确切 Agent target（server session、pane、terminal、generation、agent session），以及相对工作区的 `path`、`cursor`、`limit`；根目录 `path` 为空。
- 返回 `root`、`path`、`entries`、`next_cursor`、`revision`、`total`、`skipped`。entries 只包含直接子项，路径仍是工作区相对路径。
- 每页最多 200 项，条目 JSON 预算 192 KiB；每次最多扫描当前目录 100,000 项。只保留候选页，不把整棵树塞进内存或网络消息。
- 服务端最多两个并发目录读取，使用 5 秒上下文超时；文件系统调用的阻塞行为仍由操作系统决定。
- 游标绑定规范化 root、path 和目录版本。读取前后检查目录状态、Agent 身份与设备授权，拒绝跨目录/失效游标、路径逃逸和符号链接导航；不新增写文件权限。
- Android 读取响应还校验目录路径、版本、条目所属层级和游标前进；旧导航请求不能覆盖新目录。

只更新手机不够：旧 Relay 没有新接口，只能保留旧树浏览并显示截断/升级提示。更新电脑 Relay 时保留原来的配置、设备库和 Gateway，不需要重新配对；不要重启 Herdr 或正在运行的 Agent。
