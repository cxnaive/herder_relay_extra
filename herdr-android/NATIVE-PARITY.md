# 原生化功能与验证范围 · 0.2.11

0.2.0 的 Agent 页面和连接层均使用 Kotlin/Android 原生实现。应用运行时不再创建 WebView，也不再加载上游网页包或 JavaScript 连接桥。之前版本保存在 Android Keystore 加密主存储中的设备凭据可继续使用。

## 协议细节

- 对话数据不是伪造 UI 状态。客户端先读取历史，按 source revision、subscription ID 和连续 sequence 合并增量；发现断序/重置后重新读取。
- relay 的终端协议发送的是屏幕快照和按行复制的差分，并非通用 SSH PTY 字节流。先还原完整快照，再交给 Termux 渲染；终端产生的控制回复不会被当作用户按键发送，远端 OSC 不会自动改写手机剪贴板。
- 有副作用的请求不自动重发。连接中断或结果未知时保留输入并阻止继续发送；此状态按精确会话持久保存，返回列表、切换页面或重启应用都不会自动解除。用户查看终端后才可解除；reader 设备禁用写入操作。
- 附件上传使用上游真实的 `upload_*_result.result` 信封，最终提示中使用上游的 `Attachment: <ref>` 引用格式。
- 文件、输入和审批均绑定 relay、pane、terminal、generation、Agent session 和工作目录。切换/替换会话后丢弃旧回调，不把旧草稿直接发送到新会话。
- 网关维持回退连接，WebRTC DataChannel 重新进行独立 E2EE 握手后承载流量。直连失败回退网关。本版没有实现上游全部网络路径择优策略。

## 没有声称完全等价的部分

上游的 PWA 安装/Service Worker/网页部署更新不适用于这个原生 APK。厂商/FCM 系统推送、锁屏/生物识别锁、语音包下载管理、复杂终端菜单语义识别、Pi 运行时的所有细分状态提示、Worktree 分组批量排序，以及完整的管理员重置流程尚未做到上游全部细节等价。

对话列表目前最多保留 2,000 条已加载消息；终端读取默认 500 行。终端没有直接选区复制和鼠标模式，使用“搜索 / 复制”打开可选择文本。附件中断需要重新选择，不提供跨进程断点续传。终端尺寸调整会受 relay 租约时间约束。大图片与超长记录在真机的性能仍需测试。

Pi 的提示投递使用上游专用 lease，投递后提示结果未确认；Pi/Oh My Pi 附件能力未开放。真实 Agent 的权限提示、各厂商 Android 输入法、不同 NAT 网络的 WebRTC 升级/回退、隐私输入与后台行为仍需现场联调。高级管理操作已经按上游协议接入，但自动化端到端验证主要覆盖配对、对话、终端、审批、附件和文件。

## 0.2.5 查看器边界

全屏图片可缩放/拖动（相对适合屏幕的 1–16 倍）；PDF 单页翻页/跳页/缩放重绘；Markdown 原生排版/源码/字号/本地链接导航。大型图像和 PDF 渲染不超过 8 百万像素和 8192px 边长。完整文件最多 12 MiB，分片校验通过才交给查看器。HTTPS 外链确认后仍由系统浏览器打开，不在 App 内自动下载；不支持工作区外路径、PDF 密码和批注。旋转/Activity 重建后不持久恢复查看器当前缩放/页码。

`workspace_file_read_v1` 只提供只读能力，不提供保存 revision，也不声明 `workspace_mobile_files_v1`。Robolectric 没有实际 PDF JNI；PDF UI 测试使用由测试 PDF 经 Poppler 渲染的页面，真实 Android PdfRenderer 测试位于 `NativePdfReviewerTest`，需要连接测试设备后运行。

## 0.2.6 Codex 文件引用

正文和 Markdown 查看器新增 Codex `:codex-file-citation` 解析。指令形式的工作区 PDF/Markdown 与普通链接走同一个查看入口；不写回原始聊天内容。双 PDF 正文链接、文档卡片和各自的精确目标由原生 UI 自动测试覆盖。本次没有改动 PDF 渲染实现，仍保留上文真机验证边界。

## 0.2.7 历史缓存与连接边界

缓存只在 App 当前进程内，4 个精确会话/8 MiB/10 分钟上限；不提供磁盘离线历史。跨会话、generation、cwd、source revision 不混合；实时订阅必须重建。Relay 保留独立的 15 分钟快照/游标缓存。普通历史页最多 256 KiB；超大单条仍可能带 truncated 标记。

当前 App 的配对与传输安全策略是 HTTPS/WSS：不要求 DNS 域名，但 IP 地址必须有匹配 IP 的受信任证书。裸 IP+HTTP/WS 的内网/VPN专用模式尚未实现；本次没有修改 Android cleartextTraffic 或系统 TLS 校验。
