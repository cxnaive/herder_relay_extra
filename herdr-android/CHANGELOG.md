# Herdr Pocket 更新记录

## [Unreleased]

### Fixed
- Codex 完成提醒要求同一连接、同一绑定下先观察到该轮运行，再获得明确的同轮成功结束证据；不再把短暂 idle、其他轮完成或断连后的旧记录当作完成。提示改为“本轮完成”，保留去重；未观察到运行阶段的短任务不补报。
- 配合 Relay codexfix.19 显示 `--no-daemon` / 内嵌模式已验证会话的本轮用时，缺失记录不再冒用其他后台。版本升至 0.2.31 / versionCode 34，签名与配对不变。
- 显示经核验的关联历史只读状态；当前主会话未确认时不再隐藏唯一可读历史，但仍禁止发送、审批及实时完成提醒。明确区分关联历史与当前主会话，保留原缓存与草稿身份。


## [0.2.24] · 2026-11-04

### Added
- 配对前必须确认电脑名称：链接自带名称会预填，无名称时需填写；空名称、超长或含换行的名称不能保存，取消不会添加电脑。
- 设备卡片支持重命名电脑，仅修改当前手机的备注；离线和只读设备也能改名，不更改 Relay 地址、身份、配对、权限或既有电脑/工作空间折叠状态。其他手机的名称不受影响。

### Fixed
- 配合 Relay codexfix.12 验证终端主进程、runtime 和会话存储；明确显示验证中、失联、歧义、冲突及只读历史状态，禁止未验证的输入和审批。
- 临时失去证据时保留原会话缓存、草稿与阅读身份；恢复同一主会话不再当作换 Agent。旧请求随绑定租约撤销，真正替换主会话仍拒绝旧目标。

### Changed
- versionCode 升至 27；与 Relay codexfix.12 配套更新，沿用原签名及配对，Gateway codexfix.6 不变。

## [0.2.23] · 2026-11-04

### Added
- Android 0.2.23：电脑和工作空间可分别展开/折叠，按身份记住本机偏好；同名项目和不同服务会话保持独立，离线或暂无工作空间的电脑也有分组入口。
- 搜索时临时展开匹配的两级分组，显示匹配数；清空搜索恢复原状态。收起工作空间不隐藏路径和「＋ Agent」，折叠不影响连接、监控和完成提醒。

### Changed
- 从 GitHub Actions 的固定签名产物发布三种 ABI 的 Debug/Release APK，保留此前证书，覆盖安装不需重新配对；附件包含来源与校验文件。

## [0.2.22] · 2026-11-04

包含此前未单独发布的 0.2.21 UI 打磨；Relay/Gateway 不变。

### Added

### Fixed
- 终端读取更早输出显示进度，补载/异步刷新保留阅读位置，读取失败保留已读画面；拖到顶部只读请求更多行，没有更多行时说明上游限制并可切对话或明确发送远端翻页。
- 修正退格与 Ctrl/Alt 等旧 tmux 风格按键名，导航键发送 Herdr 可接受的固定终端序列；只读/断线/未确认输入禁止操作，旧菜单及迟到快照不影响新 Agent。

### Changed
- Android 0.2.21：以 Impeccable 的原生 Android 方法打磨深色界面，共享配色、字体层级、按钮和图标；Agent 按工作空间展示更紧凑的条目，不再重复显示 Tab 名称。
- 对话去掉重复装饰徽章，运行状态和计时保持清晰但占用更少高度；统一 Markdown、两层工具折叠、消息输入区及文件查看页，保留原有功能与访问边界。
- 手机保持底部导航，600dp 以上使用侧边导航；大字体、窄屏和键盘高度下保留正文空间与 48dp 共享操作目标。

## [0.2.20] · 2026-11-03

包含此前未单独发布的 0.2.18 / 0.2.19 修复；Relay/Gateway 不变。

### Fixed
- Android 0.2.20：下载/草稿导出写入完成后，查询系统实际文件名，若被改后缀则尝试恢复完整原名并再次验证；自定义后缀、无后缀、原本就是 `.bin` 的文件均按原名处理，不再仅依赖 MIME 映射。
- 改名导致 URI 变化时使用新 URI 核对；拒绝改名、同名冲突、继续强制后缀或无法读取名称时保留已保存内容，显示未能完全恢复的说明、原名/实际名称及复制原名按钮。不删除或另找路径覆盖同名文件。
- Android 0.2.19：按原文件后缀为系统保存窗口和分享面板提供 MIME 类型，不再让 APK/PDF/ZIP 等默认按通用二进制保存；APK 优先标为 Android 安装包，而不是根据内容嗅探标为 ZIP。原文件名不变，不自动追加 `.bin`。
- 完整下载并校验后的本地副本，交给系统保存窗口时不再依赖已退到后台的对话/查看器状态；网络分片阶段仍保留确切 Agent、权限及取消校验。
- Android 0.2.18：发布标签、仓库名和仅提及的附件名不再被自动包装成工作区文件卡片，避免点击后提示“Workspace file was not found”。普通代码片段只在明确路径或常见项目文件名时推断文件；显式 Markdown/Codex 文件引用仍不限文件类型。
- 找不到显式引用文件时显示中文说明及实际尝试读取的完整路径，不自动跨目录寻找同名文件；原有工作区/可选只读文件系统权限边界不变。

## [0.2.17] · 2026-11-03

### Added
- Android 0.2.17 + Relay codexfix.11：超出 12 MiB 预览限制或不支持预览的文件仍打开详情；可下载/分享原文件，分片写缓存、显示进度并支持取消，不整文件堆入内存。
- 对话与 Markdown 中的本地文件链接支持压缩包、CSV、代码、无后缀等普通文件，不再限制为 PDF/Markdown/图片；明确路径也可通过文件卡片打开。
- 设备页增加默认关闭的“工作区外文件访问”：仅当前控制者手机可为自己启用，Relay 持久化并逐次校验；开启后文件页可返回 `/`、跳回 Agent 工作目录或输入绝对目录，只扩展只读访问。关闭会取消当前读取/下载；不删除已导出的手机文件。

### Fixed
- Android 0.2.16 + Relay codexfix.10：大图/工具输出挤出最近日志窗口后，实时同步按已有游标补回中间记录，不再让命令数更新而中途说明和看图调用缺失。
- 手机刷新或重连时按新读到的连续页面补齐当前轮次，不能因为旧缓存里有用户消息就提前停止；补回的中间页插入正确位置，并保持工具双层折叠外的文字/图片展示。
- Codex 工具的结构化图片结果不再当作巨量 Base64 文本占用历史页；保留工具路径及正常文本输出，图片继续通过鉴权工作区读取。
- 补齐有时间/页数/字节限制并显示进度；未能完整补齐明确提示，不清空既有历史，也不绕过会话或工作区隔离。

## [0.2.14] · 2026-11-03

### Fixed

## 0.2.11 · 2026-11-03

## 0.2.8 · 2026-11-03

- 支持纯 IP + 原生 TCP 网关，不依赖域名/HTTPS；沿用端到端加密和每设备凭据，原 WSS 模式不变。
- 配对接受 herdr-tcp 限时设备邀请，拒绝主密钥、重复参数和网关地址覆盖；保存凭据后立即确认领取。
- TCP 分帧、心跳、读写超时和发送队列有界；断线重新认证，不自动重放命令；不启动 UDP/WebRTC。
- 新增实际 TCP + 加密握手/多分片历史、重连、配对确认、篡改/超长帧拒绝测试。

## 0.2.7 · 2026-11-03

- 更早历史加载增加立即可见的等待控件、快照扫描进度、取消和重试；缩小每页请求，避免慢网下整页工具输出阻塞连接。
- 保留同一会话/版本的已读页面和最早游标；增加有界的短期内存缓存，切换会话和断线重连不再直接丢掉已读历史。
- 分片接收按无进度超时而非固定 30 秒总时限判断；直连异常回退网关并隔离迟到回调，读请求错误与写入不确定性分开提示。
- 直接 WSS 连接使用 `/ws`；无域名 IP 地址解析回归通过，仍要求 TLS，不允许裸 HTTP/WS。
