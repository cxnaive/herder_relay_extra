# Herdr Pocket 更新记录

## [Unreleased]

## [0.2.13] · 2026-11-03

### Added
- Android 0.2.13：常驻监控设置新增“测试完成提醒”和直达该提醒的声音/弹出设置，可检查通知通道静默、未选铃声、通知音量为零、手机静音/振动和勿扰等状态；测试通知不启动监控、不改真实任务或去重状态。

### Changed
- 新安装的完成提醒通道显式使用系统通知铃声及振动，常驻状态通道保持无声；覆盖安装保留用户已选铃声/静音设置，不新建通道绕过静音，不使用媒体播放绕过勿扰。

### Fixed
- Android 0.2.12：修复对话页副标题误显示排序后第一个工作空间的问题，改为按电脑、服务会话和 workspace_id 精确获取当前 Agent 的工作空间名；元数据缺失时仅使用当前 Agent 自身信息。
- 完成通知同步使用确切工作空间名称；其他电脑、同目录工作空间或空工作空间不再影响标题，列表仍保留空工作空间的新建 Agent 入口。

## 0.2.11 · 2026-11-03

- 新增用户可开启/停止的原生常驻监控服务，默认关注所有 Agent，新出现的 Agent 自动纳入；单个 Agent 的完成提醒可从卡片/对话菜单关闭并持久记住。
- 前台页面和监控共享加密连接，页面退到后台不再关闭服务连接；后台仅读取状态元数据，不拉历史或终端内容。
- Agent 完成后发原生通知，按确切会话跳转；锁屏不显示敏感正文。首次快照静默建立基线，轮次完成和重连做有界持久去重。
- 增加通知权限、通道和电池设置入口；常驻通知显示断连/待确认状态并可一键停止。撤销通知权限后停止监控并释放 wake lock。

## 0.2.10 · 2026-11-03

- 对话和终端顶部增加固定运行状态条，区分运行、等待审批/输入、完成、空闲、中断/失败；历史加载状态不再充当 Agent 状态。
- 显示 Codex 本轮真实用时，每秒更新，重新打开仍基于真实开始时间；完成后保留固定上轮时长。
- 断线、过期状态及替换会话不继续假装运行；切换页/后台取消计时，迟到响应不能覆盖其他会话。
- 无可靠开始时间时明确不显示计时，不使用消息时间、页面打开时间或线程创建时间估算。

## 0.2.9 · 2026-11-03

- 把 Agent 重命名放到列表卡片和对话的直接菜单，按 Herdr Tab 名称显示；保留同 Tab 分屏共享名称的说明。
- 工作空间标题增加新建 Agent，包含空工作空间；请求绑定确切 workspace_id / server_session_id / cwd，不再要求从全局表单猜目录。
- 接入 Codex 会话级模型及思考强度，选项来自运行时，下一轮生效；确认有效回读后提示成功，不改全局配置或中断本轮。
- 新建/重命名/模型表单增加校验、等待状态和防重复提交；模型设置支持只读查看，回执未知时要求刷新核对。

## 0.2.8 · 2026-11-03

- 支持纯 IP + 原生 TCP 网关，不依赖域名/HTTPS；沿用端到端加密和每设备凭据，原 WSS 模式不变。
- 配对接受 herdr-tcp 限时设备邀请，拒绝主密钥、重复参数和网关地址覆盖；保存凭据后立即确认领取。
- TCP 分帧、心跳、读写超时和发送队列有界；断线重新认证，不自动重放命令；不启动 UDP/WebRTC。
- 新增实际 TCP + 加密握手/多分片历史、重连、配对确认、篡改/超长帧拒绝测试。

## 0.2.7 · 2026-11-03

- 更早历史加载增加立即可见的等待控件、快照扫描进度、取消和重试；缩小每页请求，避免慢网下整页工具输出阻塞连接。
- 保留同一会话/版本的已读页面和最早游标；增加有界的短期内存缓存，切换会话和断线重连不再直接丢掉已读历史。
- 分片接收按无进度超时而非固定 30 秒总时限判断；直连异常回退网关并隔离迟到回调，读请求错误与写入不确定性分开提示。
- 直接 WSS 连接使用 `/ws`；无域名 IP 地址解析回归通过，仍要求 TLS，不允许裸 HTTP/WS。

## 0.2.6 · 2026-11-03

- 修复 Codex 原生 `:codex-file-citation{path="…" purpose="output"}` 未被识别，导致最后回复中的 PDF 没有打开入口的问题。
- 原生引用在正文中显示可点击文件名，并与现有 PDF/Markdown 文档卡片共用工作区路径校验和全屏查看器；Markdown 查看页也支持同样的引用。
- 保留代码示例和普通 Markdown 行为，拒绝畸形/重复属性，不改变外部链接或工作区访问范围。
- 增加 writer-1 同格式双 PDF、原生聊天链接/卡片点击目标、Markdown 内导航和解析边界的回归测试。
- 查看器和 PDF 加载结果改为显式投递主线程，不再依赖视图已附着时才能收到后台结果；新增未附着视图的加载失败反馈测试。

## 0.2.5 · 2026-11-03

- 用独立全屏查看页替换图片小弹窗，读取原始图像文件，支持双指/双击缩放、拖动和适合屏幕，不再局限于缩略图分辨率。
- 对话中的工作区 PDF/Markdown 引用可点击打开，并在工具折叠外显示文档卡片；Markdown 内部相对链接、标题/行号和 PDF 页码引用可导航。
- PDF 单页按需绘制、翻页/跳页，放大后在有界像素预算内重新渲染；Markdown 保留表格和代码排版，可调字号与源码切换。
- 新增只读文件分片读取，文件上限 12 MiB、每片 512 KiB，逐片/整文件核对 SHA-256；不改变现有工作区隔离和写入权限。
- 增加关闭/导航时的旧请求丢弃、文件变化拒绝、手势/排版/分页/生命周期测试。PDF 的 host UI 测试注入渲染页，另提供需要真实 Android 运行时的 PdfRenderer instrumentation 测试。

## 0.2.4 · 2026-11-03

- 连续多项工具活动合并为一个可折叠组，组内工具再独立展开参数和输出；支持流式追加和向前补页时保留两层状态。
- 修复宽屏终端背景填充在手机换行模式下产生巨大灰块和多余空白行，保留正文空格、颜色重置与链接闭合。
- 移除快照模式虚构的光标，缩小空输入框并保持多行输入能力。
- 增加原生 Canvas 渲染/交互回归测试和合成示例截图；不把截图测试等同于厂商真机验收。


## 0.2.3 · 2026-11-03

- 修复历史分页在电脑准备快照期间丢掉游标、反复只显示最新工具调用的问题。
- 加入可见的“加载更早消息”入口，并在最新片段没有用户消息时有限补读上下文。
- 为连续准备响应、快照合并、订阅保留及过期版本隔离增加 4 项回归测试。


## 0.2.2 · 2026-11-03

- 按电脑、服务会话、工作空间和 Tab 分组，显示 Herdr 的标签名字并保留标签顺序，搜索支持工作空间名。
- 内置 Inconsolata 窄等宽字体；文字按字体真实字宽渲染，中文两格，默认 14sp，字号持久化。
- 加入手机换行/原始列宽切换；修正终端测量与渲染行高不一致、固定 24 行空白和长历史全量绘制，支持可读的手机宽度及大段历史。

- 工具调用默认折叠成摘要，保留运行/失败状态；图像预览独立展示，通过原有只读工作区接口安全读取。
- 为分组、Unicode 终端布局、滚动锚点、图片路径隔离和工具摘要增加回归测试。

## 0.2.1 · 2026-11-03

- 重做聊天输入区：多行文本、附件卡片、指令入口和圆形发送按钮组成同一个圆角面板；支持逐个移除附件、上传进度和输入焦点边框。
- 对话使用独立紧凑页头，消息页隐藏应用级大标题与底栏；对话/终端/工作区改为分段切换。历史、搜索、刷新、字号和管理收纳至更多菜单。
- 区分用户消息气泡和 Agent 回复，优化间距与文本行距；实时消息在接近底部时跟随，在阅读旧消息时保留位置。
- 发送按钮根据内容及权限显示可用状态；正常发送不再弹出遮挡输入区的确认 Toast，旧页面 Toast 在销毁时取消。
- 保留原有协议和功能，回归附件逐项移除、保留草稿、真实 Android 键盘与发送按钮位置。

## 0.2.0 · 2026-11-03

- 重写为原生 Android Agent 列表、对话历史、实时消息、审批表单、终端和管理页面，移除运行时 WebView 与网页包。
- 连接层迁移到 Kotlin：原生 WSS、网关分片和挑战认证、P-256/HKDF/AES-GCM、独立设备凭据与原生 WebRTC。
- 使用 Termux 终端组件渲染 ANSI/Unicode/光标，接入原生输入、方向键、组合键、功能键和隐私输入。
- 保留附件上传、Agent 对应工作区、编辑/PDF/Markdown、下载分享，并接入原生设备/Agent/工作区管理。
- 增加真实 TLS+WebSocket+E2EE 模拟 relay，自动验证配对、凭据重连、网关、消息、终端按键、审批、附件、保存和未确认请求不重发。
- 功能覆盖与仍需联调的边界见 [NATIVE-PARITY.md](NATIVE-PARITY.md)。

## 0.1.1 · 2026-11-03

- 扫码改为 CameraX + Google ML Kit 随包离线识别模型，覆盖普通、反色、旋转与密集配对二维码。
- 扫码页增加可见返回按钮、系统返回支持、手动输入、从截图识别、自动变焦、手动缩放与点击对焦。
- Agent 对话和终端页面增加“打开此 Agent 的工作区”；文件页面显示当前 Agent 和工作目录，“返回 Agent”回到对应会话。
- 文件请求按完整 Agent 会话身份与工作目录绑定；状态刷新不再打断在途读取，会话替换时拒绝旧目标操作。
- 可直接覆盖安装 0.1.0；继续使用现有 relay 文件扩展，无需增加服务端接口。
