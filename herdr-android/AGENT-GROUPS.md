# 电脑与工作空间的两级折叠

Android **0.2.23**，本地构建。沿用现有 Relay/Gateway、手机配对、文件权限和调试签名。

## 列表层级

```text
▾ 训练机 A                         已连接 · 2 个工作空间 · 3 个 Agent
    ▾ 3d-vla                      2 个 Agent          ＋ Agent
      /work/3d-vla
        writer
        trainer
    ▸ 模型实验                     1 个 Agent          ＋ Agent
      /work/experiments
▸ 训练机 B                         已连接 · 1 个工作空间 · 2 个 Agent
```

- 点电脑标题收起或展开这台电脑的全部工作空间。
- 点工作空间标题只收起或展开其中的 Agent；收起后名称、路径、数量和「＋ Agent」保留。
- 两级默认展开。折叠状态保存在本机，刷新、连接中断、切换页面或重新打开 App 不会故意重置；电脑收起再展开，也保留各工作空间自己的状态。
- 电脑按添加顺序显示；工作空间与 Tab 沿用 Herdr 的顺序。同名电脑/工作空间不会仅凭名称或路径合并：保存状态按 Relay ID、服务会话和工作空间 ID 隔离。
- 已添加但没有工作空间信息的电脑仍有独立分组。离线电脑显示「未连接」；离线时保留的 Agent 数量和内容是此前收到的信息，不代表实时状态。

## 搜索

搜索电脑、工作空间名称/路径或 Agent 后，会临时展开匹配结果所属的电脑和工作空间。
搜索期间仍可以折叠，但不写回平时的折叠偏好；换搜索词重新展开匹配结果，清空搜索恢复原状态。
搜索结果显示匹配数与总数，不把筛选结果当作这台电脑的全部 Agent。

## 操作与安全边界

- 「＋ Agent」是独立按钮，不触发折叠；工作空间收起时仍可使用，原有控制者权限、同步状态和准确工作空间检查不变。
- 对话、终端和文件操作继续绑定对应电脑及完整 Agent 身份，不因同名 Tab 或分组折叠而切换目标。
- 折叠仅隐藏列表内容，**不关闭连接、不取消后台监控、不改变完成提醒设置**。
- 标题整块可点击，支持键盘和辅助功能展开/折叠动作；按钮至少 48dp。折叠时尽量保持所点标题的阅读位置，内容不足一屏时仍受正常滚动边界限制。

截图和布局回归使用虚构电脑与会话，通过 Robolectric 原生 Views/Canvas 绘制；不代表已完成物理手机、所有输入法或屏幕阅读器的真机验收。
